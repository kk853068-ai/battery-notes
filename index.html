02 / INTERACTIVE LAB

把公式變成直覺。

調整假設條件，觀察線性容量模型與失效門檻的關係。

教學假設，非真實預測。此工具沒有執行 CNN-GRU 或粒子濾波。

模型條件

曲線是設定值計算出的示意資料，並非電池量測資料。

這個工具怎麼算？

C(k) = C0 − r × k

到達門檻的 cycle = 向上取整〔C0 × (1 − 門檻百分比 ÷ 100) ÷ r〕

RUL = max（0，到達門檻的 cycle − 目前 cycle）

這裡以整數 cycle 判定首次達到或低於門檻；真實電池可能非線性退化，量測容量也會受到溫度與測試條件影響。

03 / ABOUT THE PROJECT

一套規則，讓筆記持續生長。

CellNotes 是以電池壽命為主題的個人知識庫，也是透過 AGENTS.md 建立可重複開發流程的實作。

為什麼做這個網站？

把容量、健康狀態、剩餘壽命與預測方法拆成能獨立閱讀的筆記，讓學習與整理研究資料有一致的入口。

每篇筆記都使用相同結構

  1. 學習目標
  2. 核心觀念
  3. 範例說明
  4. 常見誤解
  5. 重點整理
